Neon Coast Cover Studio — an offline web app that turns your photos and a caption into GTA-style multi-panel cover art, exported as a PNG to share. Pick one of six layouts (nine-grid poster, hero + 3, full bleed, quad, tilted snapshots, duo), one of five colour grades (Sunset Vice, Neon Night, Palm Gold, Teal Coast, Mono Noir), crop and position each photo per panel, edit the title and subtitle live, and export in 1080×1080, 1080×1350, 1920×1080 or 1080×1920 — all in the browser, with no upload and no network request. All art, lettering and fonts are original or SIL OFL licensed; no Rockstar logos, artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
